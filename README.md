# Inland Attendance - Admin Panel

Web admin for the Inland Attendance Windows app.

**Open:** https://aretha143.github.io/inland-attendance-admin/

- Pick the branch and enter its password. You only see that branch's data.
- Today, staff-wise attendance (check-in / check-out, break duty, overtime), all records, summary, staff management, holidays and branch rules.
- Data comes from the Supabase project `attendance`. Records older than 2 months are deleted automatically.
- Photos stay on the branch PCs and are never uploaded.

The whole panel is the single file `index.html`.
